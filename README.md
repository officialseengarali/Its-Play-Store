# Its Play Store

A Google Play Store Competitor — Full Stack React + Vite + Supabase

## Setup
1. Run `schema.sql` in your Supabase SQL Editor
2. Add environment variables (see vite.config.ts)
3. Run `pnpm install && pnpm run dev`

## Tech Stack
- React + Vite
- Tailwind CSS
- React Router DOM
- Supabase (Auth + Database + Storage)
- Lucide React
